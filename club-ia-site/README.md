# Club IA Site

Site web du club d'intelligence artificielle pour les collégiens.

## Structure du projet

- `index.html` : Page d'accueil
- `style.css` : Feuilles de style globales
- `script.js` : Scripts JavaScript
- `pages/` : Pages de contenu du site
  - `activites.html` : Nos activités
  - `programme.html` : Le programme annuel
  - `projets.html` : Projets des élèves
  - `prompts.html` : Guide sur les prompts
  - `ressources.html` : Ressources utiles
  - `securite-ethique.html` : Sécurité et éthique dans l'IA
- `images/` : Ressources graphiques
  - `logo.png` : Logo du club
  - `favicon.ico` : Icône du site
